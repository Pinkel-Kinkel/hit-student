# HIT Recordings

מורידים הקלטות Zoom של שיעורים ב-HIT בלחיצה אחת: מעתיקים את הקישור מה-Moodle, מדביקים, ומקבלים את הסרטון ואת התמלול בעברית כקובץ טקסט.

## התקנה

1. נכנסים ל-[Releases](../../releases) ומורידים את `HIT-Recordings.zip`.
2. מחלצים את הקובץ לתיקייה כלשהי (למשל `D:\HIT`).
3. מפעילים את `HitRecordings.exe`.

בפעם הראשונה ש-Windows שואל "Windows protected your PC", לוחצים **More info** ואז **Run anyway**. ההודעה מופיעה כי התוכנה לא חתומה דיגיטלית.

## איך משתמשים

1. מעתיקים מה-Moodle את הקישור להקלטת הזום.
2. פותחים את האפליקציה. הקישור כבר יופיע בשדה.
3. אפשר לכתוב שם, למשל `הרצאה 1`. אם משאירים ריק, משתמשים בשם מהזום.
4. לוחצים **Download**.

**בפעם הראשונה בלבד** ייפתח בתוך האפליקציה דף ההתחברות של HIT / Zoom. מתחברים פעם אחת, וההורדה ממשיכה לבד. האפליקציה זוכרת את ההתחברות לפעמים הבאות.

## מה מקבלים

- `הרצאה 1.mp4`: הסרטון.
- `הרצאה 1 תמלול.txt`: התמלול (אם יש להקלטה תמלול), מחולק לפסקאות עם חותמות זמן.

הקבצים נשמרים ב-`D:\HIT\Zoom Recordings` (או `Documents\HIT Recordings` אם אין כונן D). אפשר לשנות את התיקייה עם **Change** בתחתית החלון.

## דרישות

- Windows 10 או 11 (64-bit).
- [yt-dlp](https://github.com/yt-dlp/yt-dlp): אם הוא לא מותקן, האפליקציה מתקינה אותו לבד דרך `winget` בהורדה הראשונה.

## פרטיות

ההתחברות שלך לזום נשמרת רק במחשב שלך, בתיקייה `browser-data` שליד האפליקציה. שום דבר לא נשלח לשום מקום חוץ מ-Zoom עצמו. אל תשתפו את התיקייה הזו עם אחרים.

## שימוש הוגן

הכלי נועד ללמידה אישית בלבד. אם המרצה כיבה את אפשרות ההורדה, כבדו את זה: אל תפיצו ואל תעלו את ההקלטות לשום מקום.

## בנייה מהקוד

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

הסקריפט מוריד את ה-WebView2 SDK של Microsoft, מקמפל עם הקומפיילר של .NET Framework שמגיע עם Windows, ושם את התוצאה ב-`dist\`.
