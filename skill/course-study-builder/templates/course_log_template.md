## 2. מטרה ותפקיד
לימוד ממוקד מבחן: לסנן את מה שמיותר במצגות, להשלים מה שחסר, ללמד שיטת פתרון.
Claude בונה לכל שבוע דף לימוד ו-PDF עם מפנים, לפי הסקיל course-study-builder.

## 3. מבנה התיקייה
```
<COURSE>/
├── <this log>.md
├── שיעור N/ (מצגות)  └── תרגילים/ (targ, solut, tirgul…)  └── עם מפנים/
├── מבחנים/
├── דפי לימוד/  (שבוע-N.html)
└── כלים/       (pointers_weekN.py)
```
מוסכמות בשמות הקבצים: targ = גיליון, solut = פתרונות, tirgul = תרגול …
